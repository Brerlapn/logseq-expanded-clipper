Connection

Enable the HTTP API in Logseq: Settings → Developer → HTTP API server. Copy the token shown there and paste it below.

Default is 12315

CLI integration

Optional power tier: with the Logseq CLI and the native messaging host installed (see native-host/install.sh in the repo), captures route directly to any graph — no graph switching — and tag fields are read live from the graph.

Capture

Each graph the extension has seen open in Logseq appears here with its own capture page. Leave a capture page blank to use that graph's daily journal. To add a graph to this list, open it once in Logseq.

Tag Properties

Configure tags for Tag Properties mode. Each tag has a list of typed fields that appear in the capture modal.
